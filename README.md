# kd-oad-encoders

## Setup

Clone this project with submodules
```bash
git clone --recurse-submodules https://github.com/sag111/kd-oad-encoders.git
```

If its already cloned
```bash
git submodule update --init --recursive
```

Install requirements 
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e kdoad
pip install -e testra
```
